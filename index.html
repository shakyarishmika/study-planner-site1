Help & install tips

Quick answers if your phone or PC shows a warning.

How do I install on Android?
  1. Tap Download for Android and open the APK file.
  2. If asked, allow Install unknown apps for your browser or file manager.
  3. Tap Install, then open Study Planner and allow notifications.
Windows says "Windows protected your PC"

The installer is not code-signed yet, so Windows shows this for new apps. Click More info, then Run anyway.

Do I need an account?

No. The app works fully offline. Create a free account only if you want your planner to sync between devices.

Are reminders available on Windows?

Reminders work on the Android app. On Windows, your upcoming classes, tasks and exams show on the Today screen.
